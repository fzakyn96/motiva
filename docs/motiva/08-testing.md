# Testing & Definition of Done

- Setiap domain behavior wajib memiliki test: Unit, Feature, Authorization, Workflow.
- Approval test minimum: unauthorized user ditolak, wrong step ditolak, double approval ditolak, step tidak dapat dilewati, dll.
- Definition of Done: rule terdokumentasi, tests green, diff direview, tidak ada perubahan unrelated, commit dan PR setelah review.
